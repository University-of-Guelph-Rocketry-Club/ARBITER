# ARBITER

**ARBITER** is a high-altitude balloon simulation and mission-planning tool designed for student HAB teams.

It aims to provide an OpenRocket-like workflow for modelling:

- Balloon ascent and expansion
- Burst altitude
- Parachute descent
- Atmospheric conditions
- Flight trajectory and landing zone
- Predicted versus real flight telemetry

## Status

ARBITER is in early development and will initially be validated using data from a real high-altitude balloon launch.

## Goal

Make HAB mission simulation accessible, reproducible, and useful for both pre-flight planning and post-flight analysis.
